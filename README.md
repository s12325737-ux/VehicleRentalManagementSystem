# VehicleRentalManagementSystem
Java OOP Vehicle Rental Management System


Vehicle Rental Management System

This project was developed using Java and Object-Oriented Programming concepts.

Features:
- Vehicle Management
- Customer Management
- Rental Management
- Vehicle Maintenance
- Revenue Calculation

Concepts Used:
- Abstraction
- Inheritance
- Encapsulation
- Polymorphism
- Interface
- Overloading
- Overriding

Run Main.java to start the system.
